# 现场数字孪生标定闭环

## 目标与边界

本模块把港口计量、作业和环境历史导出数据转换为可复核的孪生参数及独立验证证据。当前实现标定的是港区或设备组的功率响应关系，不把单项功率模型误写成全港综合孪生精度，也不据此开放设备控制。

浏览器中的合同样例只验证计算链路。只有经授权的现场导出、明确来源责任、未参与拟合的验证时间窗、固定阈值、来源证明和独立审批全部成立，才可形成“现场标定证据候选”。生产执行仍需设备拓扑、影子运行、联锁、回退演练和现场验收。

## 输入合同

数据包版本为 `site_twin_calibration_dataset.v1`，包括：

- `site_id` 与 `dataset_id`；
- 来源系统、责任主体、使用授权、时区、提取时间和证据类型；
- 严格不重叠的训练窗口与验证窗口；
- 目标值 `observed_power_kw`；
- 吞吐量、到港量、环境温度和潮位四项业务驱动；
- 资产组、时间戳和可追溯来源记录号。

至少需要四十八条训练记录和二十四条验证记录；每个资产组至少需要十二条训练记录和六条验证记录。时间必须带明确时区，资产组与时间戳组合不得重复，物理范围异常、窗口交叉或窗口外记录均会拒绝整包。

## 标定与验收方法

1. 仅在训练窗口拟合带正则约束的多因素功率响应模型。
2. 在完全隔离的后续验证窗口计算平均绝对误差、均方根误差、归一化平均绝对误差、偏差比例和决定系数。
3. 按资产组与低、中、高吞吐工况分解误差，避免总体均值掩盖局部失真。
4. 比较训练窗与验证窗的特征均值漂移。
5. 对验证记录进行五百次配对自助重采样，形成归一化平均绝对误差的百分之九十五置信区间。
6. 使用代码内预声明阈值，不能由请求临时放宽：归一化平均绝对误差不高于百分之十二、绝对偏差比例不高于百分之五、决定系数不低于零点七五、最大标准化特征漂移不高于一点五。

生成的 `site_twin_calibration_evidence.v2` 证据包含数据摘要哈希、模型版本、各资产组参数、时间窗、误差、阈值结果、漂移诊断、误差分解、来源记录摘要哈希和证据内容摘要哈希，不包含原始现场记录。审批人必须与数据责任主体不同，审批人与变更单均须使用稳定标识。

## 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| `GET` | `/api/v3/twin-calibration/readiness` | 查看数据合同、固定阈值、已配置证据状态和安全边界 |
| `POST` | `/api/v3/twin-calibration/run` | 计算标定候选；不保存、不审批、不授予生产权 |
| `GET` | `/api/twin-calibration` | 读取部署环境指定且通过校验的版本化证据 |

## 生成版本化现场证据

先把授权导出转换为输入合同，再执行：

```bash
.venv312/bin/python -m scripts.calibrate_site_twin \
  --input site-calibration-dataset-2026-01.json \
  --output site-calibration-evidence-2026-01-v1.json \
  --authorized-source-attested \
  --approved-by site-model-risk-reviewer \
  --change-ticket CHG-2026-001
```

命令拒绝覆盖已有文件，确保旧版本、失败版本和审批记录全部保留。完成独立复核后，将新证据文件路径配置到 `PORT_DT_TWIN_CALIBRATION_PATH`。系统会重新校验证据内容摘要、训练与验证窗口、固定阈值、来源类型、审批人和变更单；仅修改路径或顶层状态字段无法通过生产就绪门禁。

## 后续现场验收

- 将码头操作系统作业事件、计量系统功率与设备资产组按同一时间基准对账；
- 分别标定岸桥、场桥、水平运输、冷藏箱、岸电和储能等子模型；
- 为预测区间单独做覆盖率校准，功率点预测通过不能代替预测区间验收；
- 在影子运行中比较孪生预测、现行调度和实际结果；
- 经过漂移监测、人工复核、联锁、回退演练和港口验收后，仍由独立执行门禁决定控制权限。
