# 顶级港口系统对标、数字孪生与全业务闭环核查（V6）

核查日期：2026-08-30

## 结论

本仓库已经形成可训练、可回放、可审计、可替换现场数据的离线工程基线，但**尚未达到“马上接入真实港口并投入生产”的级别**。当前可以开展的下一阶段是：接入只读现场数据、完成字段映射和校准、运行影子策略、进行硬件在环和独立验收。当前不得自动更改靠泊计划、放行船舶、批准航行、创建作业工单或向设备下发命令。

阻止立即接入的不是再增加几个页面或离线指标，而是八类现场适配器均未配置，现场数据血缘、身份权限、时间同步、实测校准、影子运行、联锁回读、连续运行和独立验收证据均不存在。系统继续保持：

- `production_authority=false`
- `dispatch_allowed=false`
- `live_data_verified=false`
- recommendation only / fail closed

## 顶级系统能力基线

本次把下列能力作为对标基线，而不是只比较三维界面：

| 顶级系统能力 | 本仓库现状 | 结论 |
|---|---|---|
| 港口全域数字孪生、实时海事态势与规划仿真 | 已有实体/业务图谱、公开数据连续回放、压力场景、预测和审计；没有授权 TOS、AIS/VTS、设备和水文实时源 | 软件基线具备，现场保真度未证明 |
| Port Call 到离港事件协同、参与方确认和时序优化 | 六方协同、延误传播、冲突消解、建议版次和回执合同已实现；没有真实参与方身份和共享计划写入权 | 可影子联调，不可承诺 ETA/ETD 或资源 |
| 港口社区/供应链可视化、闸口铁路驳船联动 | V6 已把闸口、铁路、驳船拆成独立状态、动作和业务指标；没有预约、班列、驳船实绩 | 离线策略覆盖，现场数据为空 |
| 标准化互操作 | 已覆盖 DCSA Port Call、IMO Maritime Single Window、IHO S-100 内部映射与失效安全门 | 内部映射不是外部认证或主管机关接收回执 |
| 水文气象、航道、富余水深和封复航权威 | 已有公开再分析、富余水深和封航硬约束 | 不能用于导航；必须接港口/VTS/水文主管机关源 |

## 数字孪生数据完整性逐项核查

训练数据共 17,544 个连续小时，另有独立的 2026 年 3,624 小时前向挑战集。可追溯的外部观测是交通运输部上海港集装箱吞吐量官方汇总锚点，以及洋山附近公开气象/海洋再分析。闸口、铁路、驳船、冷藏箱、岸电、维护、引航、拖轮、危险品和资源容量是预先声明的确定性工程场景，不是上海港码头实测遥测。

| 现场域 / 适配器 | 离线场景是否有字段 | 真实现场数据是否齐全 | 上线前必须替换/补齐 |
|---|---:|---:|---|
| TOS：船期、泊位、箱位、作业量、实际时间 | 是 | 否 | 计划/实绩、事件时间、箱/任务身份、来源所有者和逐字段血缘 |
| AIS/VTS：船舶、航道、引航、拖轮 | 是 | 否 | MMSI/航次、ETA/ATA、航道状态、引拖申请和实绩、主管机关时间戳 |
| 气象/水文：风浪流、潮位、封复航 | 公开再分析 | 否 | 港区站点、权威潮位/水深、封复航事件、质量码和新鲜度 |
| 能源 SCADA/EMS/BMS：电表、岸电、储能 | 是 | 否 | 计量点、费率、荷电状态、功率/爬坡、告警、读回和结算边界 |
| 设备 PLC：岸桥、水平运输、场桥 | 是 | 否 | 设备状态、任务、moves/h、故障码、联锁和动作回读 |
| 闸口/铁路/驳船 | 是 | 否 | 预约、到达、通过、班列和驳船计划/实绩、容量和取消事件 |
| 冷藏箱 | 是 | 否 | 箱 ID、插拔、设定/实测温度、告警、服务和电量 |
| CMMS/人员 | 是 | 否 | 工单、故障、备件、剩余寿命标签、班组和能力资质 |

现场替换数据集必须至少满足：720 个无间断小时、V6 全部输入逐字段 99% 覆盖、授权导出证明、同一 `site_id`、来源清单哈希、现场时区和每字段 measured/authorized-derived 血缘。公开数据集会被该门禁明确拒绝，不能静默冒充现场数据。

## 强化学习业务覆盖与设计

### 覆盖边界

V6 将业务域扩展为 13 个。9 个域有 RL 或独立优化器输出：船舶到港与泊位、岸桥装卸、堆场、水平运输、闸口/铁路/驳船、微电网储能、冷藏箱/岸电、设备维护、监管延误韧性。4 个域不设置独立 RL 优化器：气象海况与封航、安全审批与回滚、成本碳峰值核算、跨港迁移与漂移治理。这四类采用确定性规则、核算、监测和治理更合适。

### 观测

V6 使用 110 维观测：53 个测量或场景特征、显式可用性掩码、归一化运行状态，以及监管积压、闸口、铁路、驳船、引航、拖轮、岸桥、水平运输、场桥、冷藏、维护、岸电和能源等有记忆的业务压力。缺失字段不填成“正常值”，而是保留 availability mask。

### 动作

18 个连续建议动作分别为：储能功率、服务强度、柔性负荷、泊位优先、堆场流入、查验缓冲、监管恢复、闸口平滑、铁路分配、驳船分配、冷藏服务、岸电分配、维护储备、引航分配、拖轮分配、岸桥分配、水平运输分配、场桥分配。

引航与拖轮、铁路与驳船、岸桥与水平运输与场桥不再共用一个动作。动作仅为资源比例或建议值，不包含船舶放行、航行批准、作业指令或设备执行权。

### 奖励与硬约束

奖励同时记录成本、碳、峰值、安全、延误，以及闸口、铁路、驳船、引航、拖轮、冷藏、岸电、维护、监管、三段装卸链、资源失衡、动作抖动和潜在动作修正。奖励分项进入逐步审计账本，不使用前端随机曲线。

下列安全和法律边界不允许 RL 通过奖励权重“学掉”：储能荷电状态/功率/爬坡/期末可达域、封航和富余水深、危险品堆场流入、冷藏最低保障、维护最低储备、闸口/集疏运/海事服务/三段装卸最低服务承诺。海事/海关放行、航行批准、设备联锁、计划承诺、身份权限和人工审批始终在 RL 之外。

### 正式训练与冠军证据

最终 V6 运行使用 Stable-Baselines3 SAC，在 2024–2025 连续包的严格时间切分上完成 3 个随机种子 × 30,000 个真实优化步，训练时禁用渲染；种子 626、726、826 的模型和验证指标均追加保留。验证段选中种子 726（`rl-20260830T070107706Z`），选模后才打开 2026 年 3,624 小时独立前向挑战集，并执行 20 个成对 48 小时窗口。

冠军在前向挑战上的综合业务价值相对 FCFS 平均提升 15.77%（95% CI 10.18%–21.18%），相对透明固定规则代理平均提升 22.94%（19.17%–26.49%）。闸口、铁路、驳船、引航、拖轮完成率分别为 100.00%、99.92%、99.91%、93.12%、95.12%；岸桥、水平运输、场桥三段完成率均为 100.00%；基础服务完成率 80.22%，监管放行完成率 92.65%，岸电服务率 66.86%。守护栏违规率为 0，期末 SOC 误差为 0，动作投影严重度均值约 2.92e-10，潜在动作修正均值 13.54%。

19 项业务、安全、投影、训练和独立评测门槛全部通过，状态为 `ADMITTED_OFFLINE_CHAMPION`。这里的“冠军”只表示当前公开/工程离线证据中的最佳可复现候选；固定规则是透明代理而非上海港现行策略，综合业务价值也不是现场财务节省。`production_authority=false` 保持不变。

## 非 RL 功能完成度

已补齐只读 `port-snapshot.v1` 现场接入网关，覆盖八类适配器，并验证 HMAC、载荷摘要、站点身份、owner/source、新鲜度、序列、重放、单位、有限值和取值范围。网关只保存血缘摘要，不保存原始遥测或密钥；有效快照也不会授予生产控制权。

已存在并逐条运行验证的非 RL 流水线包括：现场孪生校准、只读影子验收、执行联锁验收、六方 Port Call 协同、海事标准互操作、八目标预测区间、业务价值归因、端到端资源协同、连续运行/灾备、组织职责/值班治理。它们均会在缺少现场证据时明确阻断。

## 仍缺的 P0 现场工作

1. 配置并授权八类现场适配器，完成字段身份、单位、时间戳、质量码、序列和血缘映射。
2. 使用至少 720 小时的现场数据重新校准、训练和独立测试；公开/工程容量参数必须替换为码头能力曲线和标准作业程序。
3. 绑定真实 current-operations 基线和操作员调度日志；当前固定规则只是透明代理，不是上海港现行策略。
4. 完成至少 7 个连续运营日、35 个只读影子周期，记录候选/现行策略、可行性、延迟、操作员处置和漂移。
5. 在沙箱或硬件在环环境验证 PLC/BMS/EMS/TOS 联锁、读回、重复命令、部分失败、丢失确认和回滚。
6. 接入企业目录身份、最小权限、双人审批、密钥管理、TLS、审计和现场网络安全控制。
7. 完成主管机关、港口运营、海事安全、控制工程、网络安全、法律和数据治理的独立验收。
8. 使用实际执行回执和后验计量结果开展业务价值归因；在此之前不得把离线提升写成现场节省。
