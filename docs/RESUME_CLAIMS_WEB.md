# Web端简历指标与面试证据

## 建议简历内容

**【工程1】数字孪生 AI 港口智能决策双端调度系统（独立全栈自研）**

[Web端] / [移动端] / [GitHub源码]

自主研发面向智慧港口与绿色低碳运营的数字孪生 AI 双端调度系统。Web 端负责
船舶、泊位、岸桥、AGV、堆场、岸电与储能的建模推演、RL 训练评测、策略治理
和能碳分析；Flutter 移动端负责态势感知、告警、候选策略对比、人工确认、执行
回执和审计回放，通过统一 FastAPI 形成“建模推演—人工决策—结果回传—审计追踪”
闭环。

▸ **亮点功能：** 实现 37 维港口运行观测（12 类国际港口因素及逐项可用性掩码）、
储能/服务资源/柔性负荷/泊位优先级/堆场流量 5 维联合建议动作；支持
SAC/PPO/TD3/DQN/A2C/TQC/QR-DQN/TRPO/Recurrent PPO/ARS 与 MPC、FCFS；训练阶段禁用渲染，三段时序隔离后的盲测独立生成轨迹，
动作屏蔽器约束电网容量、SOC 和期末 SOC；移动端采用幂等提交、冲突键阻断、
异人审批、服务端回执和 SHA-256 前向审计链，南向执行默认 fail-closed。

▸ **业务价值：** 基于 MPA 新加坡 2020–2025 官方月度吞吐量与集装箱船到港量
构造 52,608 条连续小时驱动记录，按 35,064/8,784/8,760 时序划分；固定协同策略
相对静态 FCFS 与固定能源时刻表，在 2025 年留出集上使泊位有效利用率由
**83.63% 提升至 91.09%（+7.45 个百分点）**，平均待泊时间缩短 **16.94%**，
情景用电成本降低 **11.80%**；365 个完整测试日的 2,000 次成对 bootstrap 和
27 组参数敏感性均完成复算。（参数预声明的数字孪生情景对照，非港口实测 KPI
或因果效果；泊位缓冲未使用现场结果标定）

▸ **技术栈：** 原生 Web（HTML/CSS/JavaScript）+ FastAPI/Pydantic + Flutter/Dart +
Gymnasium + Stable-Baselines3/SB3-Contrib/PyTorch + 10 类 RL + SciPy MPC + FCFS +
NumPy/Pandas + Docker + GitHub Actions

## 面试边界

- 业务 KPI 来自冻结的协调策略反事实，不是 RL 已收敛或已在现场部署的证据。
- 泊位与待泊增益来自 4 h/船和 2 h/船缓冲假设的透明对照，不是因果识别结果。
- MPA 月度吞吐量和到港量是官方锚点；小时负荷、电价、碳因子及物理参数为情景派生。
- Web 实现多智能体业务编排与联合动作控制，不能称为现场分布式 MARL。
- 当前 Web 前端不是 React；公开技术栈不得写成 `React + FastAPI`。
