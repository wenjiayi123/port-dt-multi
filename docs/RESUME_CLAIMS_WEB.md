## 建议简历内容

[Web端] / [移动端] / [GitHub源码]

自主研发面向智慧港口与绿色低碳运营的数字孪生 AI 双端调度系统。Web 端负责
船舶、泊位、岸桥、AGV、堆场、岸电与储能的建模推演、RL 训练评测、策略治理
和能碳分析；Flutter 移动端负责态势感知、告警、候选策略对比、人工确认、执行
回执和审计回放，通过统一 FastAPI 形成“建模推演—人工决策—结果回传—审计追踪”
闭环。

▸ **亮点功能：** 实现 37 维港口运行观测（12 类国际港口因素及逐项可用性掩码）、
储能/服务资源/柔性负荷/泊位优先级/堆场流量 5 维联合建议动作；支持
SAC/PPO/TD3/DQN/A2C/TQC/QR-DQN/TRPO/Recurrent PPO/ARS 与 MPC、FCFS；训练阶段禁用渲染，三段时序隔离后的盲测独立生成轨迹，
动作屏蔽器约束电网容量、SOC 和期末 SOC；移动端采用幂等提交、冲突键阻断、
异人审批、服务端回执和 SHA-256 前向审计链，南向执行默认 fail-closed。

▸ **业务价值：** 构建 37 维观测、5 维联合建议动作、12 类国际港口现实因素及逐因素可用性掩码的 `port_ops_v3` 强化学习环境，将服务强度、泊位优先级和堆场流量与作业电负荷显式耦合；保留 BTS/NOAA 洛杉矶港 2021 公开对照包的 87,459 个六分钟时步、262,347 条独立公共原始观测和 69,967/17,492 时序划分。新增上海目标包，对齐交通运输部 22 个官方吞吐报告锚点与洋山附近 17,544 小时公开气象/海洋再分析，共 17,566 条独立公共来源观测，按 12,280/1,755/3,509 进行训练—验证—封存盲测。SAC/PPO/TD3/DQN/A2C/TQC/QR-DQN/TRPO/Recurrent PPO/ARS 均完成至少 3 个随机种子 × 10,000 步无渲染训练，形成 33 个通过证据门禁的 RL 正式运行（SAC 保留安全投影加固前后两代各3种子）和 4 个确定性控制基线运行（MPC/FCFS 各2个）。经验证集选定的 3 种子 SAC 在 10 个未触碰的 48 小时盲测窗口上，相对中性 FCFS 的五指标加权优势为 **2.95%（95% CI 1.68%–4.00%）**，吞吐提升 **8.40%（3.56%–11.47%）**，延误指标改善 **16.77%（9.78%–21.38%）**；等吞吐强度口径下，单箱成本和单箱碳排放分别改善 **4.11%（2.33%–5.03%）** 和 **3.90%（1.49%–5.54%）**，固定 48 小时情景机械年化约为 **663.28 万元**与 **4,998.58 吨 CO₂e**，硬约束越界率和期末 SOC 误差均为 0。该策略严格优于 FCFS，但未击败工程规则代理与 MPC，因此不宣称生产准入或集团实绩节省。历史 MPA Singapore 固定反事实基准仍追加保留：52,608 条小时驱动记录的 2025 留出集上，泊位有效利用率 83.63%→91.09%、平均待泊 -16.94%、情景用电成本 -11.80%，365 个测试日完成 2,000 次成对 Bootstrap 和 27 组预声明敏感性验证。跨端 500 项固定闭环操作中，重复提交抑制、冲突幂等键阻断、越权生产下发阻断和审计接收率均为 100%，生成 200 份唯一决策回执，300 条 SHA-256 前向审计链全部通过，生产执行回执为 0；当前 GitHub 发布流水线 **125 项单元测试**、依赖漏洞审计、CodeQL 与 OpenSSF Scorecard 全部通过。

## 面试边界

- V3 SAC 业务指标来自上海公开聚合/再分析数据的时序盲测；MPA 历史 KPI 来自冻结的协调策略反事实，二者都不是现场部署或因果效果证据。
- 663.28 万元与 4,998.58 吨 CO₂e 是“等吞吐强度”的 48 小时情景机械年化，不是绝对电费节省、港口实绩或审计碳核证。
- SAC 已严格优于中性 FCFS，但尚未击败工程规则代理和 MPC；因此生产准入、现场 KPI 和集团节省声明继续关闭。
- 泊位与待泊增益来自 4 h/船和 2 h/船缓冲假设的透明对照，不是因果识别结果。
- MPA 月度吞吐量和到港量是官方锚点；小时负荷、电价、碳因子及物理参数为情景派生。
- Web 实现多智能体业务编排与联合动作控制，不能称为现场分布式 MARL。
- 当前 Web 前端不是 React；公开技术栈不得写成 `React + FastAPI`。
