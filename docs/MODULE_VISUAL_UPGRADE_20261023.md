## 性能与验收

工作台按菜单加载，离开时销毁图表、观察器与内页WebGL。首页隐藏或服务台打开时暂停三维；服务台按打开/选项卡读取数据和创建图表。模型页不加载新增三维。设备、集装箱、静态岸桥和标线采用实例化/合并绘制，动画约30次/秒上限，尊重减少动态效果设置。

本机同类视角：合并前约1467次绘制，合并后约468–491次，下降约67%；一次1440×900页面首帧约4.24秒。约8–12ms为CPU提交时间，不是GPU FPS或跨机器保证。监控页原有算法首次曾等待11.36秒，其间界面可导航；不将其表述为全部秒开。

- 29个内页目标全部复查：21增强、8保留；6个独立目标含4增强、原版RL、Swagger。1440×900无横向溢出，1920×1080抽查管理、模型、治理。
- 实点服务台4视图、导出、菜单、原按钮、三维点选/方向键/暂停/复位。公开水深显示15.5m。
