# 双端系统简历指标证据

## 可写口径

- Web 业务情景：52,608 条小时驱动记录，35,064 train / 8,784 validation /
  8,760 test；泊位有效利用率 83.63%→91.09%（+7.45 个百分点，相对 +8.91%），
  平均待泊时间 -16.94%，情景用电成本 -11.80%。
- 稳定性：365 个完整测试日、2,000 次成对 bootstrap；三项相对指标 95% 区间
  为 8.89%–8.97%、16.92%–16.97%、11.79%–11.84%；完成 27 组预声明参数敏感性。
- 移动闭环：500 项固定 API 操作中，重复提交抑制、冲突幂等键阻断、越权生产
  下发阻断和客户端审计接收均为 100%；300 条审计事件哈希链有效，200 个唯一回执，
  生产执行回执为 0。

## 必须同时说明

业务指标是 MPA 官方月度吞吐/到港锚点驱动的数字孪生反事实，不是港口实测 KPI、
线上 A/B 或财务审计收益。小时负荷、分时电价、碳因子、气温、潮位与设备参数为
工程派生/情景参数；吞吐与到港是确定性小时分配。

移动闭环指标是本地确定性 API 语义验证，不是现场网络延迟、SLA 或设备执行证明。
生产执行默认关闭；真实接入仍需站点数据、设备白名单、约束标定、身份系统、双人
审批和独立验收。
