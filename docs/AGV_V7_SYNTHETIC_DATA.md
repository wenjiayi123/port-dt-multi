# AGV V7 训练输入说明

本次公开的 `app/services/rl_model/agv_charge/data/` 是已有的合成工程数据快照，不是码头、海关或海事机构的现场数据。原始 `port_grid_config.json` 明确标注“合成数据参数”；车辆、任务、充电、价格和碳因子字段仅用于离线训练诊断。

V7 训练使用最后 72 小时，按时间划分训练、验证与保留段，剔除跨边界转换，执行三个种子各 10,000 次 IQL 更新。九个输入文件的 SHA-256 保存在 `evidence/v7/agv_charge/runs/agv-iql-v7-20260907T031350Z/manifest.json`，原文件没有为本次发布修改。

这份快照能够重现已记录的训练输入，但没有声称可由已公开生成器重新生成，也不提供现场数据来源或授权证明。行为数据中的下一状态不构成新策略动作的反事实结果；当前 AGV 模型没有通过业务价值准入，不用于实际调度。

重现命令：`python -m scripts.audit_agv_iql_v7`。该命令追加新运行目录，保留旧模型和旧日志。
