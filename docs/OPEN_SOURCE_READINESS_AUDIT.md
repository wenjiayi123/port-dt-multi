# 开源与生产就绪审计

审计日期：2026-07-20。结论：项目已具备可信的开源研究/集成主链路；默认配置不应宣称为生产港口实时控制系统。

| 模块 | 当前驱动 | 本次处理 | 生产前仍需 |
|---|---|---|---|
| RL 训练 | SB3 SAC/PPO/TD3/DQN | 已替换本地假进度；训练回调拥有状态和指标 | 在目标运算预算上执行已提供的多种子基准命令，完成现场约束验收 |
| 控制基线 | SciPy MPC | 与 RL 共用环境和留出集评测 | 港口设备模型辨识与求解时限验收 |
| 数据集 | 公开输入 + 明示工程派生 | 规范契约、哈希、时间切分、上传映射 | 替换为获授权的港口历史数据 |
| 训练/渲染隔离 | 独立环境实例 | 训练禁止 render/trace；测试后生成轨迹 | CI 持续验证与运行资源隔离 |
| RL 首页与面板 | 后端状态/历史/评测 | 删除本地进度和演示收益曲线；增加模型注册、模型卡、哈希校验、晋级与回滚审计 | 现场密钥签名和独立部署审批 |
| 五算法比较 | 持久化测试登记 | 删除写死对比柱；增加多窗口、多种子、置信区间和基准命令 | 在目标运算资源上固定预算执行并审批结果 |
| PortViz | 数据集投影或 JSONL 轨迹 | 删除随机移动和静默回退，标记是否实测 | 对接 GIS/TOS/设备流并校时 |

## 已删除的误导性行为

- 前端自行推进训练进度；
- 训练时渲染画面；
- 未连接训练产物时生成奖励/收益曲线；
- 写死的 RL 与基线收益柱状图；
- PortViz 断线后随机移动车辆；
- 合规、平台运维、孪生校准接口失败后补固定“优秀”指标；
- 已配置真实外部接口失败后静默降级到模拟。
- 旧版随机短训、OpsX 工程模拟和无来源 TwinLab 样例的默认自动挂载行为。
- TwinPlus 上海港自动示例生成路由的默认挂载行为。
- Dashlets、PortX KPI/Pareto、EnergyX 和旧平台/Ops 生成数据路由的默认挂载行为。
- 策略与基线曲线相同时将 0 元冒充为已评定收益。

## 明确保留的模拟

仓库仍保留场景生成器和工程模拟器，因为它们对故障注入和接港前联调有价值。它们必须显式标记为 simulation/mock，不得写成实测，也不得在真实接口故障时自动顶替生产数据；未固定随机种子的模拟器只能用于界面联调，不能用于算法比较或复现实验结论。

## 不应进入公开仓库

`.gitignore` 已排除虚拟环境、训练运行目录、模型产物、审计事件、软著提交包、Word/PDF/ZIP 和旧归档。首次提交前仍应执行密钥扫描与大文件清单检查，并确认每个数据文件的再分发许可。
