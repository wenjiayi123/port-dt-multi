# 港口多目标预测与不确定性校准

本模块把港口运行中最常被用于调度决策的八类预测，统一放进可复核的时间留出评估合同。它不是把页面上的平滑曲线换一个名称，而是要求每条样本同时记录特征冻结时间、预测签发时间、业务目标时间、结果观测时间和来源记录；任何使用目标发生后信息的样本都会被拒绝。

## 八类固定预测目标

| 业务目标 | 主要输入因素 | 输出 |
|---|---|---|
| 船舶预计到港时间 | 距港距离、航速、航道等待、风速、水流 | 到港所需分钟数 |
| 泊位作业时长 | 装卸量、岸桥数量、岸桥效率、劳动力可用率、堆场拥堵 | 作业分钟数 |
| 岸桥作业效率 | 设备年限、风速、劳动力可用率、堆场拥堵、设备可用率 | 每小时作业自然箱数 |
| 堆场拥堵程度 | 堆场占用、闸口排队、计划卸船量、铁路积压、水平运输可用率 | 零至一拥堵比例 |
| 设备故障风险 | 累计运行时间、振动、温度、近期故障、维护逾期 | 零或一实发故障结果及校准风险 |
| 天气停工风险 | 风、浪、能见度、降水、雷暴距离 | 零或一实发停工结果及校准风险 |
| 监管作业延误 | 查验负荷、单证完整度、危险货物、主管机关队列、异常数量 | 延误分钟数 |
| 港区能源负荷 | 船舶靠泊、岸桥作业、冷藏箱、岸电、堆场占用、环境温度 | 千瓦负荷 |

输入特征名称和顺序属于固定合同。现场可以更新数据适配、模型参数和证据版本，但不能通过临时删除困难目标来提高通过率。

## 时间顺序与防止信息泄漏

每个目标必须声明互不重叠的训练窗、校准窗和测试窗，并以业务目标发生时间分窗：

一、训练窗只拟合岭回归参数；

二、校准窗只计算绝对残差分位数，形成百分之八十和百分之九十五预测区间；

三、最后的测试窗只计算误差、区间命中率、区间宽度、特征漂移和风险概率校准指标，不能再选择模型或调整阈值。

每条记录必须满足“特征快照时间不晚于签发时间，签发时间早于目标时间，目标时间不晚于实测时间，实测时间不晚于数据提取时间”。设备故障和天气停工使用实际发生的零或一结果，不能把模型给出的概率再次作为所谓实测值。

## 固定门禁

八类目标必须同时满足：归一化平均绝对误差不高于零点二；百分之八十区间经验覆盖率不低于零点六五；百分之九十五区间经验覆盖率不低于零点八五；两个区间的归一化平均宽度分别不高于零点七五和一点一；训练窗到测试窗的最大标准化特征均值偏移不高于一点五。两个风险目标还要求布里尔分数不高于零点二二、期望校准误差不高于零点二。

区间使用按时间切分的绝对残差保形校准。这里报告的是留出窗口上的经验覆盖率，不宣称时间序列未来仍保持可交换或分布不变；漂移、业务规则或数据源变化后，必须生成新版本证据并重新审批。

## 现场证据和生产边界

浏览器合同样例每类目标使用二十四条训练、二十四条校准和二十四条测试记录，只证明字段、模型和度量链能够执行。现场证据至少要求每类目标七十二条训练、二十四条校准和二十四条测试记录，并满足：

- 来源类别为 `authorized_site_forecast_export`，且对签发记录、特征快照和后验实测来源完成授权证明；
- 八类目标全部通过固定门禁，留出预测回执与数据集、模型包摘要绑定；
- 运营计划、模型风险和海事安全三名复核人互异，且均独立于数据责任主体；
- 绑定稳定变更工单，并以新文件保存，禁止覆盖旧证据。

只有这些条件同时成立，`site_forecast_service_accepted` 才为真。即使通过，`forecast_advisory_only` 仍为真，`automatic_resource_commitment_allowed`、`dispatch_allowed` 和 `production_authority` 始终为假；预测不能自动修改靠泊计划、承诺泊位或岸桥资源，也不能直接控制设备。

## 版本化核验

合同计算：

```bash
.venv312/bin/python -m scripts.verify_forecast_uncertainty \
  --input private/forecast_input.json \
  --output private/forecast_evidence_v1.json
```

现场证据还必须显式声明来源证明、三方复核和变更工单：

```bash
.venv312/bin/python -m scripts.verify_forecast_uncertainty \
  --input private/forecast_input.json \
  --output private/forecast_evidence_v2.json \
  --authorized-source-attested \
  --operations-planning-approved-by reviewer-operations \
  --model-risk-approved-by reviewer-model-risk \
  --maritime-safety-approved-by reviewer-maritime \
  --change-ticket change-2026-001
```

命令拒绝覆盖已有文件。生产环境通过 `PORT_DT_FORECAST_UNCERTAINTY_PATH` 指向私有、版本化证据，并要求它与现场图谱、标定、影子验收、执行放行、靠泊协同和标准互操作证据使用同一个 `site_id`。

## 页面按钮边界

“预测校准”页签包含“刷新预测状态”“查看校准合同”“运行留出评估”三个按钮。最后一个按钮只将内置合同样例发给无副作用计算接口，不保存输入、不形成现场批准、不触发调度资源承诺或设备指令。页面固定显示“合同通过不等于现场服务水平”。
