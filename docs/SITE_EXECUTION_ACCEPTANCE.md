# 现场执行联锁与受控放行

这一环节位于“现场孪生标定”和“只读影子运行验收”之后。它解决的不是策略效果问题，而是一个更严格的问题：即使建议正确，系统能否保证错误资产、越界参数、过期确认、重复指令、回执丢失、联锁跳闸或回退失败时，设备不会被错误控制。

默认边界始终是：模型只产生建议，执行接口不赋予模型生产控制权。现场执行验收通过后，每一条真实指令仍必须由申请人与另一名确认人逐单复核，并经过独立的设备联锁。

## 固定验收矩阵

现场调试证据必须对同一执行配置摘要各提供且只提供一条以下记录：

1. 安全指令下发并完成设备状态读回；
2. 参数越界时在下发前拦截；
3. 确认超时后禁止执行；
4. 重复指令被幂等机制拦截；
5. 设备确认回执丢失时不得推定成功；
6. 独立联锁触发后禁止执行；
7. 急停触发后禁止执行；
8. 回退后读取设备状态并确认恢复。

六类拦截场景的设备指令执行数必须为零，安全指令与回退的读回覆盖必须为百分之百，联锁跳闸与急停覆盖必须为百分之百。缺项、重复、摘要不一致或指标被修改都会使验收失败。

## 执行配置要求

`config/actuators.example.json` 使用 `site_actuator_config.v2`。正式配置必须包含：

- 稳定的现场标识以及明确的授权现场模式；
- 精确到资产和动作的白名单，不允许用资产类型兜底放行；
- 每个动作必填参数及其上下界或允许值；
- 资产的精确南向路由、独立联锁标识、读回方式和回退能力；
- 十五秒至三百秒的短时确认有效期；
- 异人双通道确认、设备读回、独立联锁和回退强制开关。

生产通道只接受带读回的超文本传输安全协议控制网关、开放平台通信统一架构或带读回的工业以太网通信。当前消息队列遥测传输只完成发布，没有相关设备回执关联，因此不会被认定为生产执行成功。

## 证据生成与绑定

浏览器中的“运行合同预检”只校验字段、固定场景和计算规则；它不读取现场密钥、不保存工单、不审批，也不调用设备执行接口。因此即使合同样例通过，页面仍显示“合同通过不等于现场放行”。

真实港区应在私有环境中导出现场调试数据，然后运行：

```bash
python scripts/verify_site_execution.py \
  --input private/evidence/site_execution_commissioning_2026_03.json \
  --output private/evidence/site_execution_acceptance_2026_03_v1.json \
  --authorized-source-attested \
  --operations-approved-by terminal-operations-reviewer \
  --maritime-safety-approved-by maritime-safety-reviewer \
  --controls-engineering-approved-by controls-engineering-reviewer \
  --change-ticket CHANGE.EXECUTION.2026.03
```

脚本只写入一个新的版本化证据文件，拒绝覆盖已有文件，也不会下发设备指令。运营、海事安全、控制工程三名审批人必须互不相同，并且都不能是数据责任主体。

部署时同时设置：

```bash
PORT_DT_ACTUATOR_CONFIG=/absolute/private/path/actuators.json
PORT_DT_EXECUTION_ACCEPTANCE_PATH=/absolute/private/path/site_execution_acceptance_2026_03_v1.json
```

就绪检查会重新解析两个文件，验证内容摘要、现场标识和审批合同，并要求它们与图谱、标定和影子验收属于同一现场。仅设置路径、把 `enabled` 改为 `true`，或让软件合同样例通过，都不能打开生产执行门。

## 单条指令生命周期

1. 人工指令或经过软件安全包络的强化学习建议进入暂存；
2. 网关重新检查执行配置、白名单、精确路由和参数边界；
3. 生成带配置摘要、指令摘要、有效期和申请人信息的原子证据包；
4. 与申请人不同的人员通过独立通道在有效期内确认；
5. 确认时再次校验配置摘要、指令摘要、白名单、路由和参数边界；
6. 南向适配器执行后必须取得相关设备读回，发布成功不等于设备成功；
7. 独立联锁、急停和现场操作规程始终拥有更高优先级；
8. 回退必须再次确认，并用设备状态读回证明恢复。

超时、证据篡改、配置变更、确认人相同、回执缺失或现场验收失效时，链路均失败关闭。系统不把推荐、暂存工单、设备执行和最终现场授权混为一件事。
