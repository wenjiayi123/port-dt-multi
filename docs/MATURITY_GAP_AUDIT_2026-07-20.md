# 成熟数字孪生 RL 决策系统差距审计

审计日期：2026-07-20。对标维度包括数据治理、可复现 RL 评测、模型生命周期、安全边界、孪生语义、运行可观测性、网络安全和开源供应链。

| 原差距 | 风险 | 已完善 |
|---|---|---|
| 数据只能加载，无训练前质量门 | 时序/物理错误进入策略 | 质量 API、单位、物理界、时间间隔、异常值、治理元数据；失败时阻断训练 |
| 公开数据边界不够醒目 | 把集成固件误当单港实测 | 新增数据卡，明示新加坡吞吐与旧金山潮位的地理不一致及全部派生列 |
| 单次/单种子评测 | 算法排名不稳定 | 默认 10 个留出窗口、逐轮指标、自助法置信区间、3 种子基准命令和汇总 API |
| 训练产物无注册/晋级流程 | 无法回答“现在用的是谁” | 模型卡、SHA-256 复核、`candidate/champion/rollback/archive` 别名、人工审批原因和 JSONL 审计 |
| 策略、仿真和归因存在生成值 | 把界面可视化误当模型证据 | 策略只读模型登记；仿真改为留出集评测适配；无归因算法时明确返回不可用，不生成伪 SHAP |
| 状态 API 暴露本机路径并嵌入完整轨迹 | 泄露工作站信息并放大响应 | 公共 API 仅返回证据 ID/摘要；评测轨迹经独立路由按需获取 |
| 推理值缺少独立安全判定 | 分布外输入或越界动作 | 分布、SoC、BESS 功率/爬坡、服务强度、柔性负荷和需量包络；输出永远无自动执行权 |
| 孪生对象只有页面概念 | 资产、属性、关系与来源不可验证 | DTDL 兼容 JSON-LD 模型、实体关系图契约、来源时间戳和校准证据门 |
| 默认通配 CORS，无统一认证 | 开源部署后 API 暴露 | 开发/生产模式分离、显式 CORS、API Key 常量时间比较、生产文档关闭和上传限制 |
| 无统一运行状态 | 故障时无法快速定位 | `/health/live`、`/health/ready`、`/metrics`、请求 ID、安全响应头和故障处置手册 |
| 本机联动携带开发者绝对路径 | 开源泄露、误启动外部进程 | 默认不挂载桌面启动路由，改为环境配置且 API 仅返回脱敏状态 |
| 演示执行链可生成闭环结果 | 未下发却被当作现场成功 | 旧执行路由默认不挂载；新网关默认关闭，强制白名单、参数约束、幂等、异人复核、独立二通道密钥和可重试回滚审计 |
| 供应链只有基础 CI | 依赖漏洞与发布来源不透明 | Dependabot、PR 依赖审查、CodeQL、tag 源码产物证明、非 root 容器和 Issue 模板 |
| 发布依赖含已知高风险版本 | 模型加载和运行时供应链风险 | PyTorch/SB3 升级到当前安全版；CI 安装后每次运行 `pip-audit --local` |
| 首页仍后台请求已关闭或未配置的演示路由 | 控制台 404/5xx，执行语义混乱，并可能把空值误读为零指标 | 船期、OpsX、孪生校准和工程模拟器均按后端能力开关挂载；默认首屏无失败探测；首页和 RL 面板只读 `/api/actuators/capabilities`，明示评测不授予设备执行权 |
| 数据契约区写死 `mock-ready`，需量曲线由电价合成 | 静态标签被误当接入证据，合成曲线被误当预测 | 首页契约区改读 `/api/system/provenance` 与南向能力接口；外部模拟适配器默认不请求；需量只接受适配器明确提供的 `demand_series`，缺失时显示未接入 |
| 来源状态与 PortViz 启动响应暴露本机绝对路径 | 泄露维护者目录和现场网关信息 | 只公开 `artifact_id`，真实 REST 状态不返回私有 `base_url`，并加入 API 回归测试 |
| 生产边界散落 | 开源可运行被误读为港口已验收 | 模型治理、生产检查清单、故障手册、项目治理与安全报告边界 |

## 当前结论

代码仓库已达到“可审计的开源研究/集成平台”的发布边界，默认开启的主链不再依赖伪进度、写死算法结果或无来源港口数据。

它仍不是“换一个数据集就可直接自动控制港口”的成品。下列内容不可由公开仓库代替：

- 获授权的真实港口数据、设备拓扑和现场标定；
- PLC/BMS/TOS 独立安全联锁、TLS/网关、密钥管理器和最小权限；
- 运营、电气、网络安全、法务与数据治理责任人签批；
- 影子运行、故障演练、回滚演练和持续漂移/效果监控。

这些现场项目在 [PRODUCTION_READINESS.md](PRODUCTION_READINESS.md) 中保留为必经人工验收门，系统不伪造完成状态。
