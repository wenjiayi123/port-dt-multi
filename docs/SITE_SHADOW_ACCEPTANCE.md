# 现场影子运行与上线验收

本模块补齐“候选策略离线评估完成”到“可进入现场上线评审”之间的证据闭环。影子运行始终为只读建议：系统读取与现行策略相同的观测，保存候选建议回执并与现行策略的实际结果对照，但不向设备、生产系统或船岸协同链路发送控制指令。

## 验收对象

每个影子周期必须同时绑定：现行策略版本、候选策略版本、现场孪生标定证据摘要、孪生图谱摘要、现行策略实测来源、候选建议回执、数据质量结果、安全守护栏结果、动作可行性、建议时延和运营人员处置意见。一个汇总数字不能替代逐周期证据。

候选策略的能耗、吞吐与延误结果在只读影子阶段属于反事实预测，不是现场实测收益。系统只把现行策略结果标为实测基线，并明确保留“候选业务效果未实测”的边界。

## 固定门槛

- 至少三十五个有效影子周期，覆盖至少连续七个运营日；
- 安全守护栏违规率必须为零；
- 数据质量失败率不高于百分之一；
- 建议不可用率不高于百分之一；
- 可行动作不可行率不高于百分之二；
- 运营复核未覆盖率和复核拒绝率均不高于百分之二十；
- 候选预测的能耗、吞吐和延误退化率分别不高于百分之五；
- 建议时延的第九十五百分位不高于两千毫秒。

这些阈值写在服务端固定合同中，输入文件不能降低门槛。验收证据保留脱敏周期记录，因此指标、连续天数、安全违规率、时延分位数和复核覆盖均可重新计算。

## 现场批准条件

浏览器接口只验证合同样例，固定使用“来源未证明”模式，不能保存或批准现场证据。只有离线工具同时满足以下条件，才能生成可供部署门读取的版本化证据：

1. 输入属于经授权的现场影子导出，且来源证明已完成；
2. 现行策略结果均有可追溯的实测来源，候选建议均有可追溯的决策回执；
3. 全部固定验收门通过；
4. 运营审批人与海事安全审批人彼此独立，且都不同于数据责任主体；
5. 证据绑定变更单和已经完成的回退演练文件，且演练文件包含成功执行、成功回退、时间顺序和具名审批；
6. 证据内容摘要校验通过，且图谱、标定和影子证据属于同一现场。

即使上述证据通过，本模块仍保持设备指令关闭、生产控制权关闭。现场控制还必须由独立联锁、最小权限执行网关、人工最终确认和故障回退机制共同决定。

## 生成版本化证据

```bash
python scripts/verify_site_shadow.py \
  --input private/site_shadow_observations.json \
  --output private/evidence/site_shadow_acceptance_2026_02_v1.json \
  --authorized-source-attested \
  --operations-approved-by terminal-operations-reviewer \
  --safety-approved-by maritime-safety-reviewer \
  --change-ticket deployment-change-2026-02 \
  --rollback-drill-reference rollback-drill-2026-02 \
  --rollback-drill-evidence private/evidence/rollback-drill-2026-02.json
```

工具会读取回退演练证据，要求其中存在成功执行回执、随后发生的成功回退回执、正确时间顺序以及具名审批与原因；只填写演练编号不能通过批准。工具拒绝覆盖已有文件。将新证据文件路径配置到 `PORT_DT_SHADOW_ACCEPTANCE_PATH` 后，部署自检会完整验证内容、重新计算指标、校验摘要，并要求它与图谱和标定证据使用相同的现场标识。

## 接口与页面

- `GET /api/v3/shadow-acceptance/readiness`：查看是否配置了可验证的现场影子证据；
- `POST /api/v3/shadow-acceptance/run`：运行无副作用的合同校验，永远不会批准浏览器输入；
- 首页 `TwinLab → 影子验收`：依次使用“刷新影子状态”“查看验收合同”“运行合同影子”完成演示。
