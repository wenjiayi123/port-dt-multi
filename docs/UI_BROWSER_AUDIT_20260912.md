## 证据与限制

本地按钮验收触发了旧版用户评测覆盖原 job 输出的缺陷。原 benchmark 与 model registry 已按 Git HEAD 精确恢复，新的评测输出封存；旧原始 evaluation/trajectory 的精确历史副本缺失，不能声明恢复了旧 raw SHA。修复后用户评测写独立版本目录；后续实际点击已经核验源 job、登记和冠军指针不变。

尚未接入的真实港口设备、现场身份/回执和桌面航行适配器没有被冒称已验收。完整自动化结果参见 [自动化审计](UI_FUNCTION_AUDIT_20260912.md)。本记录覆盖所列实际控件和关键状态，不表示穷举所有算法、参数、港口与故障组合；真实生产联动仍需现场环境验收。GitHub 提交后的版本、干净克隆与工作流结果另记发布记录。
