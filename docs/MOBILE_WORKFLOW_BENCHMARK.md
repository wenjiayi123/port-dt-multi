# 移动闭环可靠性基准

配置：`config/mobile_workflow_benchmark_v1.json`  
结果：`data/mobile/mobile_workflow_benchmark_v1.json`  
执行器：`python scripts/mobile_workflow_benchmark.py`

基准固定执行 500 项本地集成操作：

1. 100 次新的人工策略表态；
2. 100 次使用相同键与相同载荷的精确重试；
3. 100 次相同键、不同载荷的冲突重用；
4. 100 次试图从移动决策接口直接生产下发；
5. 100 次移动端审计事件上传。

| 指标 | 结果 |
|---|---:|
| 重复提交抑制率 | 100% |
| 冲突幂等键阻断率 | 100% |
| 越权生产下发阻断率 | 100% |
| 客户端审计接收率 | 100% |
| SHA-256 前向审计链 | 300 / 300 事件校验通过 |
| 生成的生产执行成功回执 | 0 |

状态采用临时隔离目录、固定时钟与原子 JSON 文件（0600 权限）重建，因此
报告可逐字段复算。它验证的是共享后端的工作流语义，不测量移动网络延迟、
真实港口可用性、生产设备成功率或业务收益。
