## 仍保留的缺项

1. 集卡周转/预约履约：缺闸口进出及预约事件，未用港口吞吐任意编造集卡量。
2. 堆存期/翻箱率：占用比例不能反推出逐箱停留时间。
3. 岸电覆盖/储能装机：需连接记录与BMS资产台账。
4. 真实船名、IMO/MMSI、AIS和实际ETA：需授权源。演示仅用DEMO编号和计划时间。
5. Scope 1及全范围碳盘查：燃油/燃气、组织边界、核验因子缺失；null不改成0。
6. 财务核证收益、ESG评级、事故、告警、工单闭环：需真实凭证或回执。
7. 现场预测准确率/孪生保真度：需授权实测和独立验证窗，不用训练误差替代。
8. 审批、设备执行权、现场准入：保持原有IAM、异人确认、联锁/回读/回滚验收。
9. 其他港口：保留对应港口自己的现场接入要求，不复制洋山为其实际业绩。

受保护的训练、堆场照明、HVAC、岸电储能、储能优化、场桥、RL Ops页面，以及独立强化学习面板不挂载本次工作台。模型注册表、权重与训练数据不修改。

## 接口与替换步骤

展示快照仍使用 `port-dt-presentation-snapshot.v1`。新增只读接口：

```
GET /api/public-port-demo/workspace?at=2025-12-15T12:00:00%2B08:00
GET /api/public-port-demo/replacement-contract
```

工作台响应包含snapshot、window、annual、metrics、coverage、site_pending。snapshot是原有展示适配器契约，其他字段由后台计算。没有向现场适配器注入模拟证据。

导出可供开发的完整模板和独立审阅报告（已有文件不会覆盖）：

```bash
.venv312/bin/python scripts/export_public_port_presentation.py \
  --at '2025-12-15T12:00:00+08:00' \
  --output /tmp/port-presentation-snapshot.json \
  --review-output /tmp/port-data-review.json
```

港口/TOS/ECS/EMS或算法输出适配器将数据映射成同一快照，写入新文件后原子替换，并配置 `PORT_DT_PRESENTATION_SNAPSHOT=/绝对路径/snapshot.json`。界面不必重写。时间戳必须含时区，缺失值用null，不把未知写成0；注明provenance.source_ref、来源及算法版本。

报表需要 `series_interval_seconds=3600` 和连续、递增、整点小时序列。乱序、重复、缺点不会生成完整窗口/分时合计。碳因子或电价不全时，该窗口碳排或金额保持null；不对缺点插值后充当实绩。外部源仅按实际提供序列计算，不自动混入内置2025年、单桥参数或伪造分表。外部源没有年报时显示未提供；完整年序列可生成其窗口合计。空间实体与实际测绘仍通过原有PORTVIZ_MODE=real适配器替换。

算法列表与评测沿用 `/api/rl/strategies`、`POST /api/rl/simulate`；用于展示的计划输出可映射到calls和series，保留算法版本/模型哈希。替换展示源不等于重新训练、现场模型验证或生产授权；这些继续走原有流程。
