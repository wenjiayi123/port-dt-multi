# Support / 支持范围

Community support is provided through GitHub Discussions for setup, data-contract and research-workflow questions. Reproducible defects belong in Issues. Security vulnerabilities must follow [SECURITY.md](SECURITY.md).

社区支持聚焦安装、数据契约与研究工作流；可复现缺陷请提交 Issue，安全漏洞请按 [SECURITY.md](SECURITY.md) 私密报告。

This project does not provide a managed port-control service, site integration SLA, safety certification or emergency operations support. Production integration requires an independent contract, site validation and operational ownership.

本项目不提供托管式港口控制服务、现场集成 SLA、安全认证或应急运行支持。生产接入必须另行完成现场验证、责任划分与变更管理。
